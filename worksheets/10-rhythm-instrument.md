# Instrument: Quarterly Operating Session Agenda + Hybrid Org Today

**Chapter 10 — The Rhythm**

One sprint is an experiment. A rhythm of sprints is a transformation. This instrument gives you the meeting agenda that locks that rhythm in place and the living document that tracks where your hybrid org actually stands — not where you planned for it to be.

---

## Part 1: The Quarterly Operating Session

Four steps, in order. This meeting happens once per quarter, after the sprint's Compound phase and before the next sprint's Signal.

### Step 1: Review the Previous Sprint

- Read the sprint outcome statement (from Deliver).
- Review the retrospective findings (from Compound).
- Answer: Did the sprint deliver against Signal's quantified cost? By how much?
- Answer: Is the workflow permanent or does it need another sprint?

### Step 2: Update the Signal Backlog

- Pull the re-ranked backlog (from Compound).
- Review each candidate: still relevant? Cost changed? New information?
- Add any new constraints that emerged during the quarter.
- Remove any that were resolved as side effects.

### Step 3: Commit the Next Sprint

- Pick the top constraint from the updated backlog.
- Name the Human Orchestrator.
- Confirm the team has the resources (people, tools, budget).
- Set the sprint start date.

### Step 4: Update the Hybrid Accountability Chart

- Make permanent any HAC rows from the completed sprint that are staying.
- Remove or revise any that didn't work.
- Note which roles have shifted since last quarter.
- This becomes the new "Hybrid Org Today" baseline.

**Pro Tip:** This meeting replaces no existing meetings. If you run EOS, this layers onto your quarterly planning — Signal Backlog maps to rocks, HAC maps to accountability chart, sprint review maps to your quarterly review. Same cadence, new layer.

**Action Step:** Put the quarterly operating session on the calendar for the end of this quarter. Book 90 minutes. Invite the leadership team. Set the agenda using the four steps above.

## Part 2: The Hybrid Org Today Document

This is the living document that captures where you actually are — not where you planned to be.

### Template

```
HYBRID ORG TODAY — [Company Name] — [Quarter/Year]

ACTIVE SPRINT
  Constraint: [one sentence]
  Human Orchestrator: [name]
  Status: [Signal / Source / Design / Build / Deliver / Compound / Complete]

SIGNAL BACKLOG (ranked)
  1. [constraint] — est. cost: $X — last validated: [date]
  2. [constraint] — est. cost: $X — last validated: [date]
  3. [constraint] — est. cost: $X — last validated: [date]

HYBRID ACCOUNTABILITY CHART
  [Role/Function] | [Agent Team] | [Human Supervisor] | [Level]
  ...

COMPLETED SPRINTS
  Sprint 1: [constraint] → [outcome in one sentence] — [date]
  Sprint 2: [constraint] → [outcome in one sentence] — [date]

NEXT QUARTERLY REVIEW: [date]
```

**Pro Tip:** This document should fit on one page. If it doesn't, you're tracking too much. The Hybrid Org Today is a dashboard, not a filing cabinet.

## Part 3: EOS/Scaling Up Integration

How the quarterly operating session maps to your existing operating system:

| Compound Rhythm | EOS Equivalent | Scaling Up Equivalent |
|---|---|---|
| Signal Backlog | Issues List (strategic) | Priorities / Rocks candidates |
| Sprint commitment | Quarterly Rock | Quarterly Priority |
| Human Orchestrator | Rock owner | Priority owner |
| HAC update | Accountability Chart review | Function Accountability Chart |
| Quarterly operating session | Quarterly Planning | Quarterly Planning |

The Compound Rhythm doesn't replace your operating system. It adds a layer specifically for AI-enabled workflow transformation. The sprint IS a rock. The HAC IS part of your accountability chart. The Signal Backlog IS your strategic issues list, focused on operational constraints AI can address.

**Pro Tip:** If you run EOS and this feels like a second operating system, you're doing it wrong. The sprint is a rock. The quarterly operating session is a 30-minute addition to your quarterly planning. The HAC is a column on your accountability chart. Same system, new capability.

## Populated Example: Ridgeline Media Group (40-Person Marketing Agency)

Ridgeline ran three sprints over three quarters. Here is their Hybrid Org Today document and Compounding Scorecard at the end of Q1 2027.

### Hybrid Org Today

```
HYBRID ORG TODAY — Ridgeline Media Group — Q1 2027

ACTIVE SPRINT
  Constraint: Proposal generation requires 12 hours of senior strategist
    time per prospect, limiting new business capacity to 4 proposals/week
  Human Orchestrator: Dana Rios (VP Strategy)
  Status: Design

SIGNAL BACKLOG (ranked)
  1. Media buying reconciliation — est. cost: $340K/yr — last validated: 2027-01-15
  2. Freelancer onboarding and briefing — est. cost: $185K/yr — last validated: 2027-01-15
  3. Campaign performance alerting — est. cost: $120K/yr — last validated: 2026-12-20

HYBRID ACCOUNTABILITY CHART
  Client Onboarding Coordinator | Onboarding Agent Suite | Sarah Chen (Client Ops) | 3
  Content Production Manager    | Content Pipeline Agent | Marcus Webb (Creative Dir) | 2
  Client Reporting Analyst      | Reporting Agent Team   | Priya Nair (Analytics Mgr) | 3

COMPLETED SPRINTS
  Sprint 1: Client onboarding bottleneck → Onboarding reduced from 3 weeks
    to 5 days, saving $984K/yr across 120 clients — Q3 2026
  Sprint 2: Senior strategist time consumed by content production → 15 hrs/wk
    of strategist time freed, reallocated to new business — Q4 2026
  Sprint 3: Analyst time consumed by client reporting → 8 hrs/wk of analyst
    time freed, reallocated to insight generation — Q1 2027

NEXT QUARTERLY REVIEW: 2027-04-14
```

### Compounding Scorecard

| Quarter | Constraint Solved | Cost Before | Cost After | Delta | Cumulative Impact |
|---|---|---|---|---|---|
| Q3 2026 | Client onboarding: 3 weeks per client | $8,200/client x 120 clients = $984K/yr | $1,900/client x 120 clients = $228K/yr | $756K/yr | $756K/yr |
| Q4 2026 | Content production: senior strategist bottleneck | 15 hrs/wk x $150/hr = $117K/yr | 3 hrs/wk x $150/hr = $23.4K/yr | $93.6K/yr | $849.6K/yr |
| Q1 2027 | Client reporting: manual analyst assembly | 8 hrs/wk x $85/hr = $35.4K/yr | 1 hr/wk x $85/hr = $4.4K/yr | $31K/yr | $880.6K/yr |
| Q2 2027 | | | | | |

Three sprints. Three quarters. $880K in annualized cost reduction, with the freed capacity redirected to revenue-generating work. The first sprint produced the largest delta — that is normal. The compounding is in the cumulative column: each sprint builds on the operational foundation the previous sprints created.

## Summary

The quarterly operating session is four steps: review the previous sprint, update the Signal Backlog, commit the next sprint, update the HAC. The Hybrid Org Today document captures the current state in a single page. The Compounding Scorecard tracks the evidence that the rhythm is producing results. Together, they turn isolated sprints into a sustained transformation cadence.
