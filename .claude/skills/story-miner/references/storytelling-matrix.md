# Storytelling Matrix (Creator Talks)

Source: https://www.youtube.com/watch?v=zSVYfQsHUxU

## Five Story Structures

1. **Linear** — Sequential narrative; removing/rearranging segments breaks it. Best for: tutorials, vlogs, history breakdowns.
2. **Listicle** — Central concept + independent related ideas; segments can be rearranged. Best for: tips, lessons, broad topic coverage.
3. **Explainer** — Complex topic broken into subtopics following logical curiosity. Best for: how-things-work, technical concepts.
4. **Problem-Solution** — Present problem, analyze root cause, deliver actionable solution. Best for: consulting case studies, transformation stories.
5. **Comparative** — Establish subjects, define criteria, share conclusions. Best for: reviews, before/after, option evaluation.

## Five Story Tactics

1. **Make Them Laugh** — Humor builds connection even in educational content.
2. **Borrow Equity** — Reference research, experts, credible sources to build trust.
3. **Lean on Fiction** — Use characters, hypotheticals, analogies to make concepts concrete.
4. **Show Don't Tell** — Demonstrate with examples rather than abstract description.
5. **Create Intrigue** — Open curiosity gaps resolved later; vary intensity.

## Five-Point Validation Checklist

1. **Comprehensive** — Does the narrative answer all critical questions?
2. **Digestible** — Is it easy to follow?
3. **Credible** — Is there sufficient evidence?
4. **Engaging** — Will it hold attention?
5. **Relatable** — Can the audience see how it fits their world?
